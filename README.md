# 🛑 Placa de Trânsito

Projeto de computação gráfica desenvolvido em **C++** utilizando a biblioteca **OpenGL**.

Este repositório contém a modelagem de uma placa de trânsito estruturada com **5 níveis de hierarquia**. Possui exemplos prático de transformações geométricas como translação, rotação, escala e grafos de cena utilizando OpenGL.

## 🛠️ Tecnologias Utilizadas
* **C++** (Lógica)
* **OpenGL** (Renderização gráfica e hierarquias)
